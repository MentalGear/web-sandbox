# Research 29: raw results

The output of each browser run of [research 29](../README.md), one folder per browser and build, one file per run. Each
line is a tag and one JSON object: `plain.run` / `lib.run` (engine, version, origin, headless, the Chromium features
switched, the frame's `allow`, the date), then one `plain.case` per case, form and variant (what script in the form's
document read at each step: `load`, `focus`, `arrow`, `chosen`, `tab`; a `*` after a value is `:autofill` true; `events`
counts the trusted `input`/`change` events and those carrying a seeded value) or one `lib.case` per form and variant
(what the guest's worker received, by step, and what the view showed at the end). `bun summarize.mjs <file> ...` prints
the compact view the README's tables were read from. No profile, database or key is kept here; the values are the
dummies of [`lib.mjs`](../lib.mjs).
